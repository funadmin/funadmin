# Admin Web

> Vue 3.5 + TypeScript + Vite 8 + Element Plus + Tailwind CSS 4 admin frontend for a Laravel admin backend.

For full documentation (in Chinese), see **[README.md](./README.md)** and the **[docs/](./docs/)** folder (`list-page`, `form-dialog`, `api`, `permission`, etc.).
