# 技术文档插件

启用插件后，公开阅读入口为 `/docs`，详情为 `/docs/{slug}`，不需要登录后台。

开发环境访问 `http://localhost:5175/docs`；直接使用 Webman 时访问 `http://127.0.0.1:8787/docs`。页面由插件自己的公共控制器渲染，独立于后台布局。

在后台「文档信息」中将可见性设为「公开阅读」，保存并发布。前台只读取当前发布修订的标题、摘要和正文。继续保存草稿不会覆盖已发布版本；归档、删除或设为「仅后台」后不再公开。修改已有文档的可见性需要发布权限。

新建文档默认公开，草稿仍不可访问。升级不会把旧的「仅后台」文档自动公开，旧文档需在后台手动调整。后台提供「前台文档」入口，以及公开文档的「公开阅读」链接。

公开页面支持目录、按范围和目录筛选、标题/摘要搜索、标题锚点、代码块、列表、表格、图片与安全链接。Mermaid 图表当前显示源码，供读者查看和复制。

页面采用简约文档布局：固定顶栏、左侧目录、居中正文和右侧页内导航。有公开文档时 `/docs` 直接展示首篇；分类和搜索使用文档列表。支持浅深色切换、`/` 或 `Ctrl/⌘ K` 聚焦搜索、代码复制和页面链接复制，手机目录与页内大纲可折叠。样式和脚本通过插件自身的 `/docs/assets/reader.css`、`/docs/assets/reader.js` 提供，无外部 CDN 依赖。

## 读者反馈（1.4.0）

公开文档的右栏（窄屏为文末）提供「本文是否对您有帮助？」。选择「有帮助」直接提交；选择「无帮助」可勾选原因并填写不超过 500 字的说明。

- 接口为 `POST /docs/{slug}/feedback`，只接受同源的 `application/json` 请求，并按来源 IP 限流（10 分钟 30 次，IPv6 按 /64 归并）。
- 访客标识由浏览器生成，库中只保存其 SHA-256，不保存 IP；同一访客对同一文档再次提交会覆盖上一次选择。
- 后台文档列表显示 👍 / 👎 计数；「更多 → 读者反馈」查看单篇文档的反馈，列表顶部「读者反馈」查看全部。需要 `document:feedback:index` 权限。

## 目录结构与排序（1.4.0）

内置文档改为扁平的阅读分组：快速入门 → 主框架开发 → 插件开发 → 官方插件 → 第三方插件。文档新增「排序」字段（0～9999，数值小的在前），决定同一目录内的菜单顺序和上一篇、下一篇。

## 从 1.3.x 升级

在插件中心对技术文档执行「更新」（会执行迁移 002 读者反馈表、003 文档排序字段），完成后重新启用。启用时：

- 仍保持内置原样的目录和文档会移动到新结构，并更新为新版正文（仍是第 1 版，不产生新的历史版本）；
- 已清空且未修改的旧内置子目录（架构设计、安装部署、后端开发、前端开发、目录与 Manifest、生命周期与权限）会被删除；
- 在后台编辑、发布、归档或调整过的文档和目录保持原样，不会被覆盖或移动。
