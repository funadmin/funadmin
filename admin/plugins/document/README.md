# 技术文档插件

启用插件后，公开阅读入口为 `/docs`，详情为 `/docs/{slug}`，不需要登录后台。

开发环境访问 `http://localhost:5175/docs`；直接使用 Webman 时访问 `http://127.0.0.1:8787/docs`。页面由插件自己的公共控制器渲染，独立于后台布局。

在后台「文档信息」中将可见性设为「公开阅读」，保存并发布。前台只读取当前发布修订的标题、摘要和正文。继续保存草稿不会覆盖已发布版本；归档、删除或设为「仅后台」后不再公开。修改已有文档的可见性需要发布权限。

新建文档默认公开，草稿仍不可访问。升级不会把旧的「仅后台」文档自动公开，旧文档需在后台手动调整。后台提供「前台文档」入口，以及公开文档的「公开阅读」链接。

公开页面支持目录、按范围和目录筛选、标题/摘要搜索、标题锚点、代码块、列表、表格、图片与安全链接。Mermaid 图表当前显示源码，供读者查看和复制。

页面采用简约文档布局：固定顶栏、左侧目录、居中正文和右侧页内导航。有公开文档时 `/docs` 直接展示首篇；分类和搜索使用文档列表。支持浅深色切换、`/` 或 `Ctrl/⌘ K` 聚焦搜索、代码复制和页面链接复制，手机目录与页内大纲可折叠。样式和脚本通过插件自身的 `/docs/assets/reader.css`、`/docs/assets/reader.js` 提供，无外部 CDN 依赖。
