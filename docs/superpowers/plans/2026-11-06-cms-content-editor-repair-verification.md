# CMS 内容编辑功能修复验证

日期：2026-11-06。

## 已处理

- 文件/图片/图集字段与封面可直接上传，上传成功绑定附件字符串 ID。继续支持附件库复用、图片预览、移除及错误提示，保存时等待上传完成。
- CMS `/admin/plugin/cms/content/upload` 先检查站点创建/编辑权限，再复用宿主上传控制器的格式/大小校验、存储、去重及钩子。无需给内容编辑者新增整个附件管理权限。
- 正文使用 Tiptap 富文本，支持标题、粗斜体、下划线、列表、引用、链接、图片、附件及撤销重做。服务端继续清理正文 HTML。
- 详情模板从当前站点主题的真实页面获取并下拉选择，排除首页、列表页、搜索页与 partials；空值继续使用栏目/模型默认模板，历史模板值可回显。
- 附件库最新页之外的已选附件也会返回；切换站点或卸载组件后的迟到上传结果不会串入新内容。执行操作时重新读取当前权限。
- 只同步本轮文件到安装副本，源包与发布后的 5 对前后端文件逐字节一致。
