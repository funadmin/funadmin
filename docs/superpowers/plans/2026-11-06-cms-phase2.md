## Constraints and decisions

- No arbitrary template functions, SQL expressions, raw HTML bypass or PbootCMS parser compatibility.
- Public order values: published_desc, published_asc, title_asc, title_desc, id_asc, id_desc; date order retains current administrative updated-time default when listing drafts. ID tie-break makes ordering deterministic.
- Offset 0..10000, limit 1..100. Full matching total remains unchanged by offset; offsets only apply to unpaginated widgets.
- Empty/falsy formatting fallback distinguishes 0/false from missing/null/empty string. Text conversion strips TrustedHtml status before final escaping.
- Scalar config calls remain unchanged. New module lists default to absent, never write examples or customer records. Only configured rows render.
- Continue from current dirty Rbac checkout to preserve ongoing CMS/editor/plugin work; do not commit/push or overwrite unrelated files.
- Builder's scope question was optional; with no response yet, use the recommended site-building track and incorporate steering if it arrives.
