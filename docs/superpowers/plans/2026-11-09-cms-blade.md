# CMS Blade Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** CMS 内置主题使用 Blade，保留受限的数据库标签及旧自定义主题兼容。
**Architecture:** 主题解析器按 .blade.php / .html 分派；Blade 每次创建隔离的视图工厂，数据访问经独立 CmsTags facade 进入原 TagRegistry。受限 TemplateEngine 只处理旧模板与数据库片段。
**Tech Stack:** PHP 8.5, illuminate/view 13, Webman, PHPUnit.
**Spec:** docs/superpowers/specs/2026-11-09-cms-blade-design.md

## Global Constraints
- 保留站点/语言/发布过滤及标签参数白名单。
- 源包与已安装 CMS 镜像同步，不修改真实数据库，不提交工作区。
- 普通变量转义，数据库片段不执行 PHP/Blade，主题 include 不得越界。

## Review Focus
- 连续渲染不同站点及主题时不得复用错误的数据或同名 partial。
- 后台片段内 @php / {{ }} 仍应为普通文本，不执行。
- 标签递归、分页主列表和调用上限不能因 Blade 接入失效。
- 自定义主题的 Blade/HTML 同名、子目录、符号链接及缺失模板行为。
- 96 个内置模板渲染后的正文/导航/分页/转义不能变化。
