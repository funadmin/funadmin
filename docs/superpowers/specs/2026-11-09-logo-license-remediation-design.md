# 字体许可与图形来源整理

用户要求处理字体与图形侵权风险。不能承诺不存在任何在先权利；本次完成可核验的字体许可、图形来源和部署替换，商标排查单独记录范围、结果与未完成项。

## 采用方案

- 字标改用 Google Fonts 上游 Manrope，固定 Git 提交、下载地址和 SHA-256，保留完整 SIL OFL 1.1 原文。导出轮廓但不改动字体文件、不以自己名义重发字体。
- 图形由自定义 32×32 网格重新绘制，保留 F 的品牌识别，取消旧版斜切和独立拼接块，采用整体折角轮廓。不得使用图库图标、其他品牌 SVG 或字体字形作为图标。
- 更新共享组件、首屏、文档站、SVG/PNG/ICO、素材包及提取目录中可确认未被用户改写的旧文件。
- 来源说明明确区分字体许可、图形绘制过程和商标检索，不把「自绘」当作「商标已清查」。待使用市场明确后，仍需检索相应国家/地区的在先商标。

## 方案取舍

保留 Avenir Next 等待购买或核对许可，会继续保留授权不确定性；采用带明确开放许可的字体更容易让项目公开分发。仅调整旧 F 的细节不能解决图形近似顾虑，因此采用独立网格重新构造。重命名 FunAdmin 不属于本次授权范围。

## 验证

检查上游原始字体与许可文件哈希、全部交付文件的来源清单、图形各处一致性、PNG/ICO 输出、素材包许可附件和前端构建；现有品牌与文档测试回归。不得把无法完成的图形商标检索写成通过。

## 用户后续选择

用户否定纯 fun 字标并明确恢复先前的斜切几何 F。当前图形已恢复该造型，字标继续使用固定版本的 Manrope；完整 OFL 许可和字体来源记录仍保留，图形商标清查状态仍为未完成。
