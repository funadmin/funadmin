# 文档公开阅读页参考设计

## 目标

将 `/docs` 公开文档页做成参考帮助中心的产品化阅读体验：顶部品牌与全局搜索，左侧章节树，中间正文，右侧当前文章目录；文章页和搜索页都保持可访问、可分享、可响应式使用。

## 范围

只调整 `admin/plugins/document/app/document/view/public/reader.blade.php`、`reader.css`、`reader.js` 以及同步的 `admin/app/document/...` 运行文件。保留现有文档查询、发布、权限、路由和内容清洗逻辑，不引入前端依赖，不改变数据库结构。

## 设计

- 顶部采用固定帮助中心导航，加入桌面端搜索框和键盘提示，移动端保留搜索按钮。
- 左侧目录保持滚动和展开状态，使用浅色分组、蓝色当前项和更清晰的层级线。
- 正文限制阅读宽度，标题、摘要、元信息、代码块、表格、提示块和上一篇/下一篇使用统一间距与边框体系。
- 右侧目录增加“本页目录”标题和当前阅读高亮；窄屏转为文章内折叠目录。
- 使用 FunAdmin 蓝色作为唯一强调色，浅色页面采用灰白背景和白色内容层，深色主题同步调整。
- 所有新增元素继续使用语义 HTML、键盘焦点、屏幕阅读器标签和现有复制/主题/进度能力。
