# FunAdmin 几何 F 品牌标志

用户从三款实际预览中选择第一款几何 F：主色蓝色、斜切横画，右上角独立拼接块体现插件扩展。FA 组合较宽，趣味 F 较活泼；选定的几何 F 更适合后台侧栏和小图标。

保留已选图形的比例，统一成 32×32 坐标。应用内使用透明底 F，沿用 `LogoMark` 的 size 参数和 currentColor 主题色；右上拼接块使用同色透明度。浏览器图标使用蓝色圆角底与白色 F。提供透明蓝色、单色、白色、横排字标与 PNG、ICO 素材。

替换共享组件、首屏加载图标、浏览器图标和独立文档站品牌标志；文档站同时更新源包和已安装模板。保持现有布局与业务功能。检验深浅背景、16/24/32 像素显示、SVG/PNG 输出与前端构建。其他会话的 Schema 组件改动保留。

## 用户追加优化

保持第一款几何 F 方向。统一 5.5 单位笔画和 2:1 斜切，细化圆角，拼接块提升至 78% 不透明度；字标间距缩小并转成固定矢量轮廓，避免系统字体替换。同步组件、首屏、文档站、图标和素材包，保留上版效果作为对比。
