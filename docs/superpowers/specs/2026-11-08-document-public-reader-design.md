# 文档公开阅读页

目标：访问者无需后台账号即可在 `/docs` 浏览、按范围与目录筛选、搜索已发布标题和摘要，并通过 `/docs/{slug}` 阅读文档。

采用插件自身的 Webman 公共控制器与服务端 HTML 页面，插件停用/卸载后入口由现有激活保护关闭。与宿主前台 Vue 页面相比，这样不用在宿主硬编码插件组件依赖；与在后台页面开放匿名访问相比，公开读写边界和后台布局明确。

公共查询仅选取 `published`、`visibility=public`、未删除并存在当前发布修订的文档，标题、摘要和正文读取不可变修订，草稿、归档、历史任意修订均不可访问。新建文档默认 public，已有 admin 文档保留其可见性；后台文档信息增加可见性选择和公开阅读链接。页面为独立目录/正文布局，支持手机、标题锚点、代码块、列表、表格、图片和安全链接。

目录只公开含可公开文档的目录及其祖先。搜索只作用于发布标题与摘要。不新增前台编辑接口，不改历史数据可见性，不引入外部 CDN。
