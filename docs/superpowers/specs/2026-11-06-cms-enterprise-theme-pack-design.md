# 企业官网主题包设计

用户要求增加几套主题，主要用于企业官网。按现有 CMS 主题目录和下拉选择机制，新增三套可独立选择的完整主题：corporate（商务蓝白）、industrial（工业科技）、studio（现代品牌）。

商务蓝白：海军蓝与白色、清晰网格、横向品牌与导航、左右分栏的品牌介绍，产品与案例以卡片呈现。工业科技：深石墨与橙色、全幅工程图形首屏、细线网格和有序的产品/项目布局。现代品牌：暖白与赤陶色、超大标题、错位构图和作品优先的版面。三者首页结构不同，内页使用各自主题的字体、间距、色彩和边框。

每套包含首页、栏目、文章、产品、案例、单页、下载、搜索和全部共用片段。产品/案例/资讯取真实已发布的本站当前语言数据，空数据提示诚实；不制造客户、营收、认证或统计数据。Logo、首页文案、联系方式、轮播/伙伴/联系人/广告继续读取现有配置。

实现选择：各主题自带完整模板和独立首页/样式，复用展示数据、基础样式和交互脚本。相较纯换色，这可以交付不同的企业版式；相较引入另一套前端框架，它保留现有 SSR、权限、SEO、路径和后台配置。新增内置主题目录描述服务统一中文名称和展示能力；只对明确内置主题启用 ThemePresentation，第三方主题保持原语义。

安全和兼容：主题扫描仍只列出实际目录及安全首页；模板解释器路径隔离不放宽。默认 detail 在所有内置主题按真实模型选布局，显式自定义模板仍优先。保留站点/语言隔离、草稿不可见、分页和搜索真实状态码。CSS/JS/SVG 本地资源，无外部 CDN、无新依赖。新主题资源和模板同步源/运行副本；不切换用户当前站点主题，不改用户内容/导航/权限。

验证：隔离 PHP 数据库覆盖三个主题的完整页面、中文/英文、数据隔离、分页、导航、配置模块及主题目录；后台验证中文选项。以当前站点数据在本机临时预览服务渲染三套主题，不修改站点记录；浏览器查看桌面和窄屏布局。
