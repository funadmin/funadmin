# CMS 优化设计

用户选择优化：公开页性能、Blade 公共层、内容编辑体验、SEO/交付、无障碍移动端、自定义表单安全。

## 方案

1. 公开页面采用共享缓存 store，缓存键包含站点、语言、规范路径、主题版本；发布内容、栏目、导航、配置或主题资源改变时使站点版本递增。响应增加 ETag 和条件请求支持，搜索、预览、表单和带身份请求不缓存。
2. Blade 主题抽取公共数据展示 partial 与主题变量层，保持每个主题的首页结构和 CSS 风格。先做低风险公共函数/数据层抽取，避免一次性重写 192 个模板。
3. 内容编辑器增加草稿自动保存（可配置时间、离开页前 flush）、批量发布/下架，以及冲突时展示服务端与本地版本摘要；服务端继续使用 lock_version。
4. SEO 增加 Open Graph/Twitter Card、模型结构化数据、RSS、分页 canonical/prev-next 和图片尺寸属性。
5. 统一主题无障碍规则：焦点可见、菜单 aria、图片 alt、减少动态效果、移动抽屉焦点回收、暗色/浅色对比度检查。
6. 表单提交强化：提交指纹防重复、表单级限流、蜜罐/验证码组合、失败审计、管理员可查看和清理提交记录；保留无 JS 结果页和站点隔离。

本阶段先完成公开缓存与 ETag、SEO 扩展、表单重复提交防护和无障碍检查基础；公共模板抽取、自动保存、批量操作作为后续独立任务，避免大范围改动与现有未提交工作冲突。
