# CMS 内容编辑修复

用户反馈：内容编辑不能上传文件，正文只有 HTML 文本输入，详情模板无法选择。本轮补齐已有内容管理流程，由当前会话直接执行，不修改其它会话正在开发的站点与主题功能。

沿用既有附件存储、校验、CSRF 与上传钩子，通过本站内容创建/编辑权限提供上传端点，响应带附件字符串 ID，上传后自动选中；附件库选择继续可用，单图和图集可预览。使用 Tiptap 提供正文富文本（段落、标题、粗斜体、列表、引用、链接、图片、撤销/重做），保存 HTML 并沿用服务端清理。相比自行维护 contenteditable，成熟编辑器能正确处理选区和粘贴；相比继续手填 HTML，编辑者能直接看到排版。

详情模板从当前站点主题的实际 HTML 页面获取，排除 partials 和首页/列表/搜索页面；空值沿用栏目/模型默认模板，旧模板值明确回显。源插件包与本地发布副本同时更新。不得覆盖并行改动，不执行数据库迁移，不自动提交或推送。

审查后补充：初始化及外部正文更新时比较编辑器投影与原 HTML。对于无法无损保留的旧表格/视频/自定义属性，显示明确提示并保留源码编辑，禁止静默转换；空正文默认富文本。
