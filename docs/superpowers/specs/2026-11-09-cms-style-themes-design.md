# CMS 多风格 Blade 主题设计

用户要求再增加几个不同风格的 CMS 主题。沿用刚完成的 Blade 引擎、现有主题选择入口和共享 CMS 数据；风格和数量由实现者选择，新增四套完整主题。

| 标识 | 名称 | 布局与视觉 |
| --- | --- | --- |
| editorial | 杂志资讯 | 纸白、墨黑和报刊红，刊头、主编栏式首屏，新闻内容优先、细分割线 |
| minimal | 极简黑白 | 大号无衬线排版，黑白与细线，目录式导航、留白和作品先行 |
| aurora | 数字科技 | 深靛背景、青紫光晕，居中首屏和数字空间插画、模块卡片 |
| heritage | 东方雅韵 | 米纸、墨绿与朱砂，宋体标题、山水图形、疏朗非对称展陈 |

每套配齐9个完整页面和15个 partial（与现有主题结构一致）。首页顺序与排版各自独立；栏目、文章、产品、案例、单页、下载、搜索和相关内容使用真实 CMS 数据，保留原有组件、无 JS 降级、多语言、SEO、导航、分页、模型字段、站点配置及轮播/伙伴/联系人/广告模块。

采用独立 Blade 目录和独立 CSS/SVG，与既有 theme-local include 边界一致，使用现有 enterprise.css 的共用基础结构。不只换颜色，也不修改主题引擎以允许跨主题 include。所有图形由本地 SVG/CSS 构成，无外部字体/CDN依赖。不向真实数据库添加演示内容，不替用户切换当前站点主题。

源码同步到 admin/app/cms，公共资源同步到 admin/public/plugin-assets/cms/public/themes；后台现有主题选择器自动发现。当前共享工作区已有多会话未提交改动，保持现有分支，不提交、重置或覆盖无关改动。

验证：新增主题选择和空站/有数据/多站多语言/全部内容模型/导航/分页及模块回归；桌面与手机宽度截图检查、横向溢出及菜单交互；源包和运行镜像一致；插件校验、PHP/CMS/宿主测试。
