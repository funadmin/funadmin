# 基于参考图优化的 F + un

保留用户提供参考图中的蓝色圆角底、大型几何 F、右上独立斜切块。在右下留白处加入小写 un，与 F 底部对齐，字重及字号经过小尺寸检查。

un 使用 Manrope 字体的 750 字重、20px 字号生成轮廓，字体许可原文与固定版本来源已附带；当前 SVG 不依赖系统字体。

提供蓝底、单色底、蓝色透明、白色透明 SVG 与 1024px 透明 PNG。source.json 保存图形及字标路径。

本版已获用户确认并应用到站点。字体许可不等于图形和名称的商标近似清查通过。

## 比例调整

按用户反馈，F 的整体线性尺寸缩小 25%，un 字号由 20 调到 23，底部作光学对齐并重新调整间距。比例稿已应用到站点。
