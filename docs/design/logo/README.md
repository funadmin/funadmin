# FunAdmin 最终 Logo

采用用户确认的几何 F + 几何 un，蓝底圆角正方形；采用选定的 A 版：F 保留无中横造型，u、n 在开口内抬高、加粗，并与竖笔底部对齐；保留几何笔画和 2:1 斜切。

图标的四个 SVG 路径全部按坐标构造，不使用字体字形或外部图标模板。独立的 FunAdmin 横排字标仍使用 Manrope，其完整 SIL OFL 1.1 许可与来源记录保留。字体许可不等于名称和图形商标已完成清查。

## 文件

- `fun-icon.svg/.png`：蓝底主标志。
- `fun-icon-mono.svg/.png`：深色底单色标志。
- `fun-mark.svg/.png`：透明底蓝色标志。
- `fun-mark-white.svg/.png`：透明底白色标志。
- `preview.png`：仅当前定稿的效果预览。
- `source.json`：几何构造与路径。
- `../funadmin-brand-assets.zip`：完整正式素材包。

正式页面资源位于 `web/public/brand/`，构建输出为 `admin/public/brand/`，字体许可位于各自的 `licenses/` 目录。

已应用到共享组件、登录/安装页、官网、文档站、首屏加载及浏览器图标。此前的其他 Logo 方案和重复解压目录已从工作区删除。
